======================================================
           සිංහල යතුරුපුවරුව (Sinhala Keyboard)
======================================================

[ පාලන යතුරු (Shortcut Keys) ]
  • ක්‍රියාත්මක කිරීම / නැවැත්වීම (ON / OFF) : Ctrl + Space
  • මෘදුකාංගයෙන් ඉවත් වීම (Exit)            : Ctrl + Alt + Q

------------------------------------------------------
[ රකාරාංශය සහ යන්සය (Rakaransaya & Yansaya) ]
------------------------------------------------------
  • kra  -> ක්‍ර       (kri -> ක්‍රි,  kree -> ක්‍රේ)
  • kya  -> ක්‍ය       (kyaa -> ක්‍යා, kyee -> ක්‍යේ)
  • pra  -> ප්‍ර       (praarthanaa -> ප්‍රාර්ථනා)
  • vya  -> ව්‍ය       (vyaapaaraya -> ව්‍යාපාරය)
  • thya -> ත්‍ය       (sathya -> සත්‍ය)
  • dya  -> ද්‍ය       (vidyaawa -> විද්‍යාව)

------------------------------------------------------
[ සාමාන්‍ය Singlish අකුරු උදාහරණ ]
------------------------------------------------------
  • k -> ක්  | ka -> ක  | kaa -> කා  | ki -> කි  | kee -> කේ
  • g -> ග්  | ga -> ග  | gaa -> ගා  | gi -> ගි
  • t -> ත්  | ta -> ත  | T -> ට්    | Ta -> ට
  • d -> ද්  | da -> ද  | D -> ඩ්    | Da -> ඩ
  • n -> න්  | na -> න  | N -> ණ්    | Na -> ණ
  • m -> ම්  | ma -> ම  | p -> ප්    | pa -> ප
