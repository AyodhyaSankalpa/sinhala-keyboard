======================================================
           සිංහල යතුරුපුවරුව (Sinhala Keyboard)
======================================================

[ පාලන යතුරු (Shortcut Keys) ]
  • ක්‍රියාත්මක කිරීම / නැවැත්වීම (ON / OFF) : Ctrl + Space
  • මෘදුකාංගයෙන් ඉවත් වීම (Exit)            : Ctrl + Alt + Q

------------------------------------------------------
1. ස්වර අක්ෂර (Vowels)
------------------------------------------------------
  • a -> අ     | aa -> ආ    | A -> ඇ     | Aa / AA -> ඈ
  • i -> ඉ     | ii -> ඊ    | u -> උ     | uu -> ඌ
  • R -> ඍ     | Ru -> ඎ
  • e -> එ     | ee -> ඒ    | ai -> ඓ
  • o -> ඔ     | oo -> ඕ    | au / ou -> ඖ

------------------------------------------------------
2. ව්‍යංජන අක්ෂර (Consonants)
------------------------------------------------------
  • k -> ක     | g -> ග     | ch -> ච    | j -> ජ
  • t -> ට     | d -> ඩ     | th -> ත    | dh / q -> ද
  • n -> න     | N -> ණ     | p -> ප     | b -> බ     | m -> ම
  • y -> ය     | r -> ර     | l -> ල     | L -> ළ
  • w / v -> ව | s -> ස     | sh -> ශ    | S / Sh -> ෂ
  • h -> හ     | f -> ෆ

------------------------------------------------------
3. මහප්‍රාණ අක්ෂර (Aspirated Consonants)
------------------------------------------------------
  • kh -> ඛ    | gh -> ඝ    | chh -> ඡ   | T -> ඨ     | D -> ඪ
  • thh -> ථ   | dhh / qh -> ධ  | ph -> ඵ | bh -> භ

------------------------------------------------------
4. සඤ්ඤක සහ වෙනත් අක්ෂර
------------------------------------------------------
  • zg / ng -> ඟ  | zj -> ඦ    | zd -> ඬ    | zdh / zq -> ඳ
  • zk -> ඤ       | zh -> ඥ    | B -> ඹ     | Lu -> ළු
  • x / zn -> ං   | X -> ඞ     | H -> ඃ

------------------------------------------------------
5. රකාරාංශය, යන්සය සහ ගයනුකිත්ත
------------------------------------------------------
  • kra  -> ක්‍ර     (kri -> ක්‍රි, kree -> ක්‍රේ)
  • kya  -> ක්‍ය     (kyaa -> ක්‍යා, kyee -> ක්‍යේ)
  • kru  -> කෘ     | kruu -> කෲ
  • kA   -> කැ     | kAa / kAA -> කෑ
